# Prompt Toolkit — Project Notes

## Design Context

### Users
Analysts, consultants, MBAs and graduates who use AI (Claude / ChatGPT / Gemini)
as a drafting tool for client-ready work. They browse this reference on a laptop
or phone, copy a prompt, and paste it into a chat. Australian-market framing.

### Brand Personality
Editorial, precise, quietly confident. Three words: **sharp, editorial,
trustworthy**. It should feel like a well-set business magazine or a museum
caption — not a SaaS landing page. Emotional goal: competence and calm.

### Aesthetic Direction
Editorial / Swiss-Modernism, **light mode**. Warm paper background (#F5F2EC),
near-black ink (#0E0C0A), a single rare gold accent (#C8900A), hairline rules
(#D6D0C4). Big serif numerals mark sections. Anti-references: neon-on-dark AI
landing pages, gradient text, glassmorphism, identical boxed card grids.

### Typography
- Display: **Playfair Display** (serif, 700/900) — headlines & numerals.
- Body: **Epilogue** (300–600).
- Mono: **JetBrains Mono** (labels, prompt bodies, buttons).

### Design Principles
1. **Gold is rare.** Accent ≤10% of visual weight; never fill areas with it.
2. **SVG icons only** (lucide-react). Emoji only inside copyable prompt bodies.
3. **No AI tells.** No gradient text, no `border-left` accent stripes, no
   glassmorphism, no pure black/white.
4. **Motion is orchestrated, not scattered.** One staggered page-load; reveals on
   scroll; transform/opacity only; honour `prefers-reduced-motion`.
5. **Mobile is first-class.** Prompt bodies wrap (never horizontal-scroll the
   page); tab row scroll-snaps; tap targets ≥44px.
6. **Content is data.** All copy lives in `src/data/*` — never hard-code prompts
   into JSX.
